How to run the project.
1. Set up virtual environment.
2. Install all dependencies from requirements.txt or pyproject.toml.
3. Set up .env file and add ELEVENLABS_API_KEY and GROQ_API_KEY.
4. You need to have ffmpeg installed and added to your environement variables path.
5. Run the gradio_app.py and go to # http://127.0.0.1:7860
